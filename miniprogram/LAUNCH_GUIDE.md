## 阶段 1 · 后端就绪(30-60 分钟)

1. 开发者工具 → 「云开发」→ 开通,创建环境,复制**环境 ID**
2. 环境 ID 填入 `miniprogram/utils/config.js` 三处 `cloudEnv`(develop/trial/release 至少填 **release**)
3. 右键部署 `cloud/functions/` 下三个云函数:`login`、`recordSync`、`dailyRemind`(dailyRemind 暂无模板可不部署,不报错)
4. 云开发控制台 → 数据库,创建 4 个集合:`users` / `records` / `subscriptions` / `analytics`(权限默认即可)
5. **关键配置**:云函数 `recordSync` → 配置 → 超时时间**调到 20 秒以上**(串行 upsert 需要)
6. 云端测试:控制台对 `recordSync` 发送 `{"action":"pull"}`,返回 `ok:true` 即通

**完成标准:开发者工具 console 无「云开发未配置,已降级为本地模式」日志,云端测试通过。**

## 阶段 2 · 合规配置(15 分钟)

1. mp.weixin.qq.com → 「设置-服务内容声明-用户隐私保护指引」→ 声明收集的信息:
   - 微信 openid(用户身份,用于数据同步)
   - 训练记录数据(重量/次数/组数,用于历史查询)
   - **不要勾选任何未实际采集的项**(位置、相册等),勾多了反而增加审核面
2. 确认小程序内 agreement 页内容与上述声明口径一致
3. (可选)申请订阅消息模板「训练提醒」→ 模板 ID 填入 `services/subscription.js`。不申请则订阅功能静默关闭,不影响提审

**完成标准:后台指引状态为「已生效」。注意:后台指引和小程序内协议页是两套独立要求,缺一常见被拒。**

## 阶段 3 · 测试与体验版(0.5-1 天)

1. 跑四套自动化测试,全绿:
   ```bash
   node miniprogram/tests/trainingSession.test.js
   node miniprogram/tests/sync.test.js
   node miniprogram/tests/services.test.js
   node miniprogram/tests/dependency.test.js
   ```
2. 开发者工具模拟器执行 `TEST_CASES.md` 的 A/B/C/D/G 组
3. 工具右上角「上传」→ 版本号 `1.0.0`,备注「首次提审」(**上传前确认代码已 commit**)
4. 后台「版本管理」→ 将该版本设为「体验版」→ 二维码发给 3-5 个健身朋友
5. 真机执行 TEST_CASES.md 的 G3(安卓必测)+ C 组(计时器恢复)+ E 组(云同步冒烟)
6. 开发者工具「审计」跑一次,处理红色项

**完成标准:TEST_CASES.md 通过标准达成(A/B/C 全过 + 安卓真机主流程 + 自动化全绿)。**

## 阶段 4 · 提交审核(材料准备)

后台「版本管理」→ 开发版本 → 提交审核,需填:

| 字段 | 填写建议 |
|------|---------|
| 版本描述 | 力量训练记录工具首版:组间一次点击记录,自动计时,云端同步 |
| 类目 | 工具 > 健康管理(阶段 0.5 已确认) |
| 测试说明 | 无需账号密码,打开即可体验全部功能(无账号体系,微信静默登录) |
| 隐私承诺 | 与阶段 2 指引一致 |
| 截图 | 审核版本截图按提示提供(工具类一般无需额外资质图) |

**提审前自查三高频驳回点**:① 隐私指引未生效 ② 类目与功能不符 ③ 名称含违规词。均已在阶段 0/2 处理。

## 阶段 5 · 发布

- 审核通过(通常几小时~1 天)→ 后台点「发布」
- **首版直接全量**(无存量用户,灰度无意义);**以后每次发新版建议用「分阶段发布」**,先放一部分观察崩溃率
- 发布后 24 小时:盯云开发控制台日志 + `monitor` 上报,关注云函数错误率

## 常见驳回速查(万一被拒)

| 拒因 | 对策 |
|------|------|
| 「请完善用户隐私保护指引」 | 阶段 2 没做透,回后台补齐后重新提审 |
| 「类目与实际功能不符」 | 确认类目是「工具>健康管理」而非「体育>在线健身」 |
| 「小程序内容与名称不符」 | 阶段 0.1 品牌名不一致导致,对齐后重提 |
| 「存在诱导分享行为」 | 检查分享文案无强制/利益诱导表述(当前文案安全) |
| 「功能不完整/白屏」 | 云函数未部署但 config 已填 cloudEnv → 部署函数或清空 cloudEnv 降级 |
