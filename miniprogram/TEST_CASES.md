## B. 核心训练流程(P0 — 主价值链路)

| # | 用例 | 步骤 | 预期结果 | 结果 |
|---|------|------|---------|------|
| B1 | 开始训练 | 首页点「开始训练」→ 选动作(如杠铃卧推) | 进入训练态,显示上次重量/次数(无历史则显示默认值) | |
| B2 | 记一组(核心!) | 点 "+" → 填重量次数 → **长按 1.5 秒** | 进度条填满 → 记录成功 → 自动进入休息计时,圆环开始倒数 | |
| B3 | 第二组预填 | 休息中点 "+" 再记一组 | 重量/次数预填上组值,组号 +1(**解决"三四组就忘"的核心卖点**) | |
| B4 | 休息计时 | 记完一组静置 | 计时按秒减少,结束时有震动/提示,状态切回训练态 | |
| B5 | 修改休息时长 | 设置中改休息秒数 → 再记一组 | 新时长生效 | |
| B6 | 撤销 | 记错一组 → 3 秒内点撤销 toast | 该组被撤销,组号回退,重量次数恢复 | |
| B7 | 漏记提醒 | 训练态静置不操作(超过阈值) | 弹出"是否漏记一组"轻提示 | |
| B8 | 完成训练 | 记完最后一个动作 → 点「完成训练」 | 进入总结态:显示组数/容量,可跳转今日总结页 | |
| B9 | 连续多动作 | 完成动作 A 后新增动作 B 再完成 | 今日总结含两个动作,数据正确 | |
| B10 | 热身组 | 记录时勾选「热身组」 | 热身不计入正式组数与总容量 | |
